# Changelog

## 1.0.0

- First release. Translates SiegeUpgrades 1.1.0 into English: the upgrade window, the ballista and
  catapult prompts, on-screen notices, log messages and config descriptions. Decimals use `1.5`
  instead of `1,5`.
- Follows the game's language setting, and switches immediately when it changes. The `Mode` setting
  can force English on or off.
